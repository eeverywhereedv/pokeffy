PokEffy

Le launcher du serveur PokEffy

The launcher for the PokEffy server

PokEffy Launcher est une application de bureau privée, non commerciale, destinée à un petit groupe d'amis qui jouent ensemble sur notre serveur Minecraft Java Edition Cobblemon. Il installe le modpack, le tient à jour et lance le jeu avec le compte Microsoft du joueur.

PokEffy Launcher is a private, non-commercial desktop application for a small group of friends who play together on our Cobblemon Minecraft: Java Edition server. It installs the modpack, keeps it up to date and launches the game with the player's own Microsoft account.

Connexion officielle

Official sign-in

Connexion Microsoft dans le navigateur du joueur (OAuth 2.0 + PKCE). Le launcher ne voit jamais le mot de passe.

Microsoft sign-in in the player's own browser (OAuth 2.0 + PKCE). The launcher never sees the password.

Propriété du jeu vérifiée

Ownership verified

Une licence Minecraft: Java Edition est obligatoire. Aucun mode hors ligne, aucun contournement d'authentification.

A Minecraft: Java Edition licence is required. No offline mode, no authentication bypass.

Modpack à jour

Up-to-date modpack

Mises à jour signées et vérifiées : seuls les fichiers modifiés sont téléchargés, les données des joueurs sont préservées.

Signed, verified updates: only changed files download and players' data is preserved.

Confidentialité et sécurité

Privacy & security

  • Les jetons d'authentification ne sont envoyés qu'aux services Microsoft, Xbox et Mojang, jamais à nos serveurs.
  • Seul le jeton de renouvellement Microsoft est conservé, dans le coffre d'identifiants du système d'exploitation.
  • Les fichiers du jeu proviennent uniquement des serveurs officiels de Mojang ; le modpack est vérifié par signature et SHA-256.
  • Aucune donnée personnelle n'est collectée ni partagée.
  • Authentication tokens are only sent to Microsoft, Xbox and Mojang services, never to our servers.
  • Only the Microsoft refresh token is stored, in the operating system's credential store.
  • Game files come only from Mojang's official servers; the modpack is verified by signature and SHA-256.
  • No personal data is collected or shared.
